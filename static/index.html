    Developer notes

    Architecture

    • Backend — FastAPI, SpotAPI for Spotify metadata (no API keys), JSON API + static SPA.
    • Downloads — yt-dlp / SpotDL, MP3 output, mutagen tags with embedded cover art.
    • Jobs — playlist downloads run server-side, so leaving the tab does not stop them.
    • Playback — server-side HTTP range streaming, no full-file download.
    • Frontend — vanilla JS, no build step, 18 CSS custom-property themes.

    Storage

    • Files live in the server's download directory.
    • Playlists, themes and job history live in this browser's local storage.
